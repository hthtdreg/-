# Сапёр!

Простая игра про минное поле.

## Возможности

* Настройка длины и ширины поля.
* Настройка количества бомб

## Стек технологий

* Python 3.14.7+
* Библиотека `random`
* Библиотека `tkinter`

## Установка

1. Скачать файл
2. Скачать python

## Использование

Запустить main.py через python
